# 競馬AIの静的Web画面

公開URL: https://isozin-ddd.github.io/keiba-value-web/

過去分析と未来予測を切り替え、オッズのスライダー・数値入力、期待値メーター、ランキング、リセット、ダーク表示を利用できます。GitHub Pagesのみで提供し、Pythonサーバーは使いません。

2026-10-27に承認済み実モデル `jra-v3-20261027` を反映しました。事前に固定した2025-10-11〜12-28の通常結果28レースでは、Brier 0.911567 / Log Loss 2.540770（既存v1は0.927120 / 2.651790）でした。ECEは悪化し、最終オッズによる参考回収率は29.96%・242点でした。利益を示す結果ではありません。最終オッズを使う事後比較モデルより精度は劣ります。

過去モードは、日付・レースIDで選んだ未使用期間の3レース48頭です。勝率、フェアオッズ、最終単勝オッズ、公式着順・払戻、モデル版と実際の予測生成時刻を表示します。発走前に配信した予想ではありません。

未来モードは正式な出馬表を取得・検査してから予測候補を生成する構成です。今回の公式取得では終了済み開催のカードしかなく、未来予測・発走前オッズとも0件です。架空の出走馬・勝率は表示しません。オッズを取得できない場合には未取得と明示し、比較用の手入力を使います。

保存データは2021〜2025年です。確認済み成績を5件持つ割合と、実際の直近5走が欠けなく揃うことは別です。未照合の中間レースの可能性が残り、2026年の過去走も未収録です。完全な直近5走や未来の精度を保証しません。

公開JSONは厳密な許可フィールドとハッシュ承認を通した `predictions.json`、`analysis.json`、`future.json` のみです。PDF、全学習CSV、馬ID、モデル重み、非公開コード、認証情報、内部ログは公開しません。

GitHub Actionsで単体テスト、390×844のChromium/WebKit操作テスト、ビルド、Pages公開、公開後HTTP確認・WebKit再検証を実施します。未来の有データ画面はテスト内だけの人工通信差替で検査し、実際の未来レース予測と区別します。実機iPhoneは未確認です。
