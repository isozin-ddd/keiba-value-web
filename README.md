# 競馬AIの静的Web画面

公開URL: https://isozin-ddd.github.io/keiba-value-web/

「過去レース分析」と「未来レース予測」を切り替えられます。スライダー・数値入力から期待値、期待回収率、期待利益率とランキングが更新されます。リセット、公式出典、ダーク表示、iPhoneサイズに対応します。

過去モードは検証済みJRAデータと承認済みモデルによる事後分析です。着順・単勝払戻を表示します。発走前に配信した予想ではありません。旧モデル成果物に厳密な予測実行時刻は記録されていないため、その旨を表示し、公開データ生成時刻と区別します。

未来モードは予測・出馬表取得・オッズ取得時刻、公開モデル版、過去走の不足を表示できる構成です。2026-10-27の公式取得では未来の馬番・斤量付き出馬表が見つからず、現在は未来予測0件です。架空の出走馬や勝率は表示しません。取得できないオッズは未取得と表示し、比較用の手入力ができます。発走を過ぎた掲載レースは未来モードから除外します。

新しい実験モデルは別期間で既存モデルより予測精度が悪化したため、公開モデルは従来の承認済みモデルを維持しています。利益・精度を保証するアプリではありません。

公開するJSONは `predictions.json`（承認済み推定勝率・最終オッズ）、`analysis.json`（同じレースの公式着順・払戻）、`future.json`（承認済み発走前予測または未提供状態）だけです。各形式は許可フィールド、確率合計、時刻を検査します。非公開側のPDF、全CSV、馬ID、モデル、認証情報、内部ログは含みません。

GitHub Actionsで単体テスト、390×844のChromium/WebKit操作テスト、ビルド、Pages公開、公開URLのHTTP確認とWebKit再検証を実行します。人工の未来画面テストは通信を差し替えたテスト内だけで使用し、公開データには配置しません。実機iPhoneでの検証は未実施です。
