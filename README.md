# 競馬AI・オッズ期待値メーター

GitHub Pages専用の静的Webアプリです。Pythonサーバー、外部ホスティング、認証情報は不要です。

公開URL: https://isozin-ddd.github.io/keiba-value-web/

`predictions.json` の `mode` に応じてデモ／検証済み実データを明示します。実データ表示の場合は、過去レースを用いた時系列テストの事後分析です。開催前に配信した予想や購入できたオッズを意味しません。

開催日・競馬場・レース選択、馬別勝率、フェアオッズ、最終単勝オッズと公式出典、可変スライダー、数値入力、期待値倍率・期待回収率・期待利益率、ランキング、リセット、ダーク画面に対応します。
不正なJSONはデモへ黙って置き換えず、読み込みエラーとして表示します。

## 検証と公開

`npm test`、`npm run build`。
GitHub Actionsで実際の表示用JSONを検証し、390×844のChromium・WebKitで操作確認した後、許可リストの静的ファイルだけをPagesに公開します。公開後もHTTPアクセスとWebKitで実際のURLを検証します。
WebKitはSafariのエンジンを使う自動テストで、iPhone実機の検証とは区別します。

このリポジトリに学習コード、モデル、PDF、収集ZIP、内部ログ、馬の内部ID、認証情報を追加しないでください。
実データは非公開本体で独立したJRA公式記録との照合、モデル評価、公開データのレビューを通した最小JSONだけを受け取ります。
